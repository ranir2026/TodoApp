# Roadmap

- [x] **Phase 1 — Core desktop app**: task/course CRUD, design system (Indigo/Amber/Violet palette, Inter type), stats bar (weekly completion, due soon, overdue), local storage.
- [ ] **Phase 2 — Design polish**: refined spacing/typography pass, hover/transition details, empty states, keyboard shortcuts.
- [ ] **Phase 3 — Metrics dashboard**: GitHub-style activity heat map, richer stats.
- [ ] **Phase 4 — Responsive layouts**: tablet/mobile breakpoints, touch targets.
- [ ] **Phase 5 — Mobile-specific interactions**: swipe actions, tap-to-expand, iPhone bookmarked-webpage support (PWA manifest, home-screen icon).
- [ ] **Phase 6 — Google Calendar sync**: OAuth login, read-only course schedule import, offline cache, settings toggle.
